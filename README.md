# Project-0
Functional Text-Based Banking Application for JFS 2471 using Java 21+, Maven, JUnit 5, SQLite and Lanterna.

## This release encompasses the work done thus far on the stretch goals of the BankCLI project and includes the following features:

- New Stylized UI Theming (Snake Branding for Background)
- Pin hash stored in database for more security in application
- Transaction timestamps stored accounting for different timezones, display of date/time on TUI formatted to be more readable and easy to understand.
- Account lock timestamp stored in database to preserve state of account even after termination of application.
- Minor Architectural changes behind scene to make backend to make repository layer read more clean.
